# Backend

The server for the bookkeeping app: Node.js (NestJS) with PostgreSQL.

Not started yet. The client app in `web/` currently runs on sample data from `web/src/app/data/sample-data.ts`; the backend will replace it with real data (accounts and logins, bank connection, documents, matching, bookings, tax filing). See the product spec in `docs/bookkeeping-portal-spec.md`.
